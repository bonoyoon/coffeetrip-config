# coffeetrip-config

CoffeeTrip 앱이 **런타임에 불러오는 공개 설정**입니다. 여기 파일을 수정하면 앱 재빌드 없이 **다음 앱 실행 시 반영**됩니다.

- `franchise_exclude.json` — 추천에서 제외할 프랜차이즈/비커피 브랜드(`excludeBrands`) + 보존 스페셜티(`keepSpecialty`).
  - 현황판 '🚫 프랜차이즈 제외' 탭에서 편집 → 이 파일에 반영(웹에서 직접 수정 또는 내보낸 내용 붙여넣기).
  - raw: https://raw.githubusercontent.com/bonoyoon/coffeetrip-config/main/franchise_exclude.json
